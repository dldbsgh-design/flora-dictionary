폴리테크니코 디 밀라노 디자인 학사(2028년 가을 입학) 준비. 입학 시험 TOLD는 이탈리아어 객관식 90문항이고, 등록 전에 이탈리아어 B2 증명서가 필요합니다.

## 한국어와 이탈리아어 섞는 비율 (사용자 요청: 한국어로만 하지 않기)

시험이 이탈리아어라서 모든 글에 이탈리아어를 싣고, 실력이 오를수록 이탈리아어를 늘립니다. 글을 쓰는 날짜로 정합니다.

| 기간 | 목표 단계 | 이렇게 씀 |
|---|---|---|
| ~2027-02 | A1 → A2 | 설명은 한국어. 소제목은 "Italiano — 한국어" 두 언어. 핵심 문장 3개 이상을 `it` 조각으로, 낱말은 `terms`로. 연습 문제 5개는 이탈리아어 문제·보기, 풀이는 한국어 |
| 2027-03 ~ 2027-08 | A2 → B1 | 위와 같고, 핵심 문장 6개 이상. 풀이 첫 문장은 쉬운 이탈리아어 + 한국어 |
| 2027-09 ~ | B1 → B2 | 설명 문단의 절반 이상을 `it` 조각(이탈리아어 + 한국어 뜻)으로. 연습 문제 풀이도 이탈리아어 먼저, 한국어 뜻은 짧게 |

- 연습 문제는 실제 시험처럼 보기 5개(A~E), 정답 하나.
- 직접 쓴 이탈리아어는 출처의 내용을 쉬운 말로 옮긴 것만. 검토자가 문법과 뜻을 확인합니다.
- 이탈리아어 출처(학교 공식 자료, Treccani, 이탈리아어 위키백과 등)를 먼저 쓰고, 한국어·영어 자료는 보조로 씁니다.

## 과목별 순서 (앞에서부터, 쓴 글 다음 차례로)

**디자인사 (월)** — 학교 무료 강의 「Introduzione alla Storia del Design」(pok.polimi.it/course/view.php?id=115)의 주차 순서를 따름
1. 산업 혁명과 디자인의 시작 → 미술 공예 운동(Arts and Crafts) → 아르누보(Liberty) → 독일 공작 연맹(Deutsche Werkbund)
2. 1910~40년대 유럽과 이탈리아: 미래주의, 바우하우스, 이탈리아 합리주의
3. 2차 대전 뒤 ~ 1970년대: 이탈리아 디자인의 성장, 대표 디자이너와 제품, 회사 (예: Olivetti, Kartell)
4. 오늘의 디자인으로

**미술사 (토)** — 시대 순서: 선사·고대 이집트 → 그리스 → 로마 → 초기 기독교·비잔틴 → 로마네스크 → 고딕 → 르네상스(초기·전성기) → 매너리즘 → 바로크 → 신고전주의·낭만주의 → 사실주의·인상주의·후기 인상주의 → 20세기 아방가르드 → 2차 대전 뒤 미술. 이탈리아 작가·작품을 먼저.

**기하와 표현 (화)** — 학교 무료 강의 「Geometria e Rappresentazione per il Design」(id=153) 1주 기하 → 2주 표현
다각형(1강 끝남) → 삼각형 → 사각형 → 원 → 각 → 둘레와 넓이 → 닮음과 피타고라스 정리 → 입체 도형 → 전개도 → 좌표 평면과 직선(해석 기하) → 대칭과 변환 → 정투상 → 축측 투상 → 투시도 → 그림·도표 읽기

**일반 상식 (목)** — 학교 범위: 고등학교 과목 + 현대의 역사·기술·과학·정치·사회. 아래 묶음을 차례로 돌림
이탈리아 현대사 → 이탈리아 국가 기관과 헌법 → 유럽 연합 → 이탈리아 지리 → 과학 → 기술 → 이탈리아 문학(단테, 페트라르카, 보카치오, 만초니 …) → 세계 현대사 → 다시 처음 묶음의 다음 주제

**논리 (일)** — 학교 범위: 추상 추론, 집합, 가정과 결론, 필요 조건과 충분 조건, 추론의 오류
집합과 벤 다이어그램 → 명제와 부정 → 필요 조건·충분 조건 → 가정과 결론 → 삼단 논법 → 추론의 오류 → 수와 도형의 규칙 찾기

**이탈리아어 문법 (수)** — 단계 순서
A1: 알파벳과 발음 → 명사의 성과 수 → 정관사·부정관사 → 주어 대명사와 essere·avere → 규칙 동사 현재형(-are, -ere, -ire) → 전치사(관사 결합형) → 소유 형용사 → 형용사 일치
A2: 근과거(passato prossimo) → 반과거(imperfetto) → 재귀 동사 → 직접·간접 목적 대명사 → 미래형 → ci와 ne
B1: 조건법 → 명령법 → 접속법 현재 → 관계 대명사 → 대과거
B2: 접속법 과거·반과거 → 가정문 → 수동태 → 간접 화법 → 제룬디오·분사 구문

**이탈리아어 독해 (금)** — 시험의 글 이해(Comprensione verbale) 연습: 짧은 이탈리아어 글 → 지문만 보고 푸는 문제. 글감은 학교 공식 안내, 디자인·미술 관련 짧은 해설, 쉬운 설명문. 저작권 때문에 남의 글을 길게 옮기지 않고, 출처의 내용을 쉬운 이탈리아어로 다시 쓴 짧은 지문을 씁니다. 단계는 위 비율 표를 따름.

## 이탈리아어 낱말 (금 오후 2시, 주 30개)
- 기존 주제 순서를 이어 가면서, 시험에 나오는 말(주제 `기하`, `미술사와 디자인사`, `시험`)을 섞습니다.
- 단계(`level`) 목표: ~2027-02 A1·A2, 2027-03~08 B1, 2027-09~ B2. 단계는 지금처럼 근거 자료가 있을 때만 적습니다.
