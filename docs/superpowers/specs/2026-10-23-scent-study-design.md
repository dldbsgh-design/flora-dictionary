설계 문서 — 꽃·향 사전 "향 공부" 권 (2026-10-23)

이 문서는 이미 공개된 꽃·향 사전 사이트(https://dldbsgh-design.github.io/flora-dictionary/)에 새 권을 더하는 설계다. 사이트 전체 설계는 `docs/superpowers/specs/2026-10-21-flora-dictionary-design.md`에 있다.

## 1. 왜 만드는가

사용자는 연습 세계(버튜버 위도)의 시그니처 향을 정하는 중이다. 사전의 향 재료로 후보 조합 두 개(A 맑은 파도, B 성스러운 바다)를 골랐지만, "탑 노트" 같은 기본 용어도 잘 모른다. 근처에 향을 맡아 보거나 조향해 볼 곳도 없다.

사용자는 향에 흥미가 생겼고, **전문 조향사의 지식 수준까지** 배워 보고 싶어 한다. 공부 방식은 정해져 있다. 사이트에 적힌 글을 읽으면서 **실물 공책에 자기 방식으로 정리**한다.

## 2. 목표, 하지 않을 것, 실패로 보는 것

**목표**
- 사전에 "향 공부" 권을 새로 만든다. 표지에서 꽃, 향과 나란히 고를 수 있다.
- 일주일에 한 주제씩 글이 늘어난다. 완전 처음("노트가 뭔지")에서 시작해 조향사 수준까지 차례로 올라간다.
- 글은 길어도 된다. 향을 직접 맡아 보지 않아도 글만 읽고 이해할 수 있을 만큼 자세히 쓴다.
- 처음 나오는 용어는 그 자리에서 풀어 준다. 왜 그런지까지 설명한다.
- 글에 나오는 향 재료가 사전에 있으면 그 항목으로 바로 갈 수 있다.
- 목차에서 전체 순서와 지금까지 나온 글을 볼 수 있다.

**하지 않을 것**
- 집에서 해 보는 과제나 실습 (사용자가 뺐다. 맡아 볼 수 없는 상황이다.)
- 짧은 요약 위주의 글 (사용자가 원하지 않았다.)
- 퀴즈, 점수, 진도 체크 기능
- 향수 제품 추천이나 구매 안내
- 회원 가입, 댓글, 사이트에서 직접 편집하는 기능

**실패로 보는 것**
- **거짓 내용**: 출처에서 확인되지 않는 내용이 사실처럼 적혀 있는 것. 사용자가 "절대 있어서는 안 된다"고 했다.
- **관련 없는 내용**: 그 주제와 상관없는 이야기로 글을 늘리는 것. 이것도 사용자가 "절대 있어서는 안 된다"고 했다.
- 책이나 다른 사이트의 문장을 그대로 옮겨 오는 것 (저작권)
- 맡아 봐야만 이해되는 설명, 풀이 없이 나오는 전문 용어
- 순서가 뒤죽박죽이라 앞 글을 모르면 뒤 글을 이해할 수 없는 것
- 휴대폰이나 패드에서 긴 글을 읽기 불편한 것
- 종이 사전의 분위기가 깨지는 것

## 3. 사용자와 조건

- 무료로만 만든다. 사이트는 지금처럼 GitHub Pages에서 돌아간다.
- 사용자는 향과 조향 지식이 거의 없다. 개발 지식도 없다. 글을 쓰고 사이트를 고치는 일은 Claude가 한다.
- 사용자는 휴대폰, 패드, 컴퓨터로 읽는다.
- 사용자는 향을 맡아 볼 기회가 없다. 글이 냄새를 대신 그려 줘야 한다.

## 4. 사용자가 정한 것

- **놓을 곳**: 노션이 아니라 사전 사이트의 새 권
- **속도**: 일주일에 한 번, 한 주제씩
- **과제 없음**: 집에서 해 보는 과제는 넣지 않는다.
- **긴 설명**: 짧고 요약된 글보다, 길어도 보지 않고 이해되는 자세한 설명
- **관련 없는 내용과 거짓 내용은 절대 넣지 않는다.**
- **읽는 방식은 Claude에게 맡김**: 사용자는 읽으면서 공책에 직접 정리하므로, 편한 방식이면 된다.

## 5. 한 주제(글)의 내용

- 몇 번째 글인지, 단계(아래 7번), 제목
- 본문: 소제목으로 나눈 긴 글. 처음 나오는 용어는 굵게 쓰고 바로 뒤에 풀이를 붙인다.
- 사전 재료 연결: 본문에 나오는 재료가 사전에 있으면 링크를 단다.
- 앞 글과의 연결: 이 글을 읽기 전에 알아야 하는 앞 글이 있으면 첫머리에 적는다.
- 출처: 글 끝에 모은다. 본문의 어느 부분이 어느 출처에서 왔는지 따라갈 수 있게 한다.
- 쓴 날짜, 마지막 확인 날짜

## 6. 정확도와 출처 규칙

- 사전의 기존 규칙(꽃말은 출처 두 곳 이상)과 같은 정신을 따른다.
- **모든 사실 설명에는 출처가 있어야 한다.** 출처에서 확인되지 않는 내용은 쓰지 않는다. (Claude가 정함)
- **핵심 정의와 숫자**(예: 노트의 정의, 농도 등급의 비율 범위)는 서로 다른 출처 두 곳 이상에서 확인한다. 한 곳에서만 나오면 쓰지 않거나, "자료마다 다르다"고 밝힌다. (Claude가 정함)
- 자료끼리 내용이 다르면 한쪽을 고르지 않고 다르다는 사실을 그대로 적는다.
- 글은 Claude가 자기 말로 새로 쓴다. 출처의 문장을 길게 옮기지 않는다.
- **비유 규칙 (사용자가 정함: 비유는 쓰되 "어느 정도는 엄격하게")**
  - 비유는 출처가 있는 사실을 쉽게 다시 말할 때만 쓴다. 비유가 새로운 사실을 더해서는 안 된다. 비유를 빼도 글의 사실은 그대로여야 한다.
  - Claude가 만든 비유에는 "비유하자면"처럼 표시를 붙여 사실 설명과 구분한다.
  - **냄새 자체를 묘사할 때**는 출처에 나온 표현(예: 사전의 "오이처럼 싱그러운")을 우선 쓴다. Claude가 냄새를 새로 지어내 묘사하지 않는다.
  - Claude가 직접 만든 비유는 구조와 원리를 설명할 때만 쓴다. 예: 향이 시간에 따라 바뀌는 순서를 공연의 흐름에 빗대기.
  - 검토자는 비유마다 원래 사실을 잘못 전하지 않는지 확인한다. 예를 들어 시간, 세기, 순서를 틀리게 떠올리게 하면 고치거나 뺀다.
  - 비유는 꼭 필요한 곳에만 쓴다. 글 대부분은 출처가 있는 설명이다.
- 믿을 만한 출처를 우선한다: 조향·향료 업계 기관(IFRA 등), 향료 회사와 교육 기관의 공개 자료, 화학 데이터베이스, 학술 자료, 백과사전. 향수 커뮤니티 후기는 "사람들이 이렇게 표현한다"를 보여 줄 때만 쓰고, 사실의 근거로 쓰지 않는다. (Claude가 정함)
- **검토**: 글마다 쓴 사람과 다른 검토자가 출처와 본문을 대조한다. 확인이 안 되는 문장이 있으면 그 문장을 빼거나 그 주의 글을 미룬다. 확신이 없는 글은 올리지 않는다. (Claude가 정함)
- **재검토**: 기존 월간 재검토 일정에 향 공부 글도 넣는다. 가장 오래 확인하지 않은 글부터 출처를 다시 확인한다. (Claude가 정함)

## 7. 순서 (초안, Claude가 정함. 사용자가 바꿀 수 있다)

단계는 입문 → 기초 → 중급 → 심화 → 전문이다. 아래는 첫 계획이고, 쓰면서 순서를 고치거나 주제를 나누고 더할 수 있다. 앞 글을 알아야 이해되는 주제는 뒤에 둔다.

- **입문**: 향수는 무엇으로 이루어지나 / 탑·미들·베이스 노트 / 향이 날아가는 빠르기와 오래 남는 정도 / 향의 계열 / 천연 향료와 합성 향료 / 향을 말로 표현하는 법
- **기초**: 향료를 얻는 방법(증류, 압착, 용매 추출 등) / 농도에 따른 이름(퍼퓸, 오 드 퍼퓸, 오 드 투왈렛 등) / 어코드란 무엇인가 / 고전적인 향의 구조(시프레, 푸제르 등) / 아쿠아틱 계열 / 머스크 / 앰버와 수지
- **중급**: 향료 분자의 기초 화학 / 고정제와 향의 지속 / 처방(포뮬러) 읽는 법 / 향료 안전과 IFRA 기준
- **심화**: 향을 평가하는 방법 / 향의 역사와 중요한 전환점 / 조향사가 향을 설계하는 과정
- **전문**: 조향사라는 직업과 교육 과정 / 전문가 수준의 재료 지식과 구조 분석

## 8. 화면

- **표지**: "꽃", "향" 옆에 "향 공부"를 더한다. 기존 표지의 권(제1권, 제2권) 형식을 따른다.
- **목차 지면**: 단계별로 지금까지 나온 글의 번호와 제목을 보여 준다. 아직 쓰지 않은 주제는 보이지 않는다.
- **글 지면**: 한 주제를 한 지면에서 쭉 내려 읽는다. 공책에 옮겨 적기 쉽게 소제목에 번호를 붙이고, 용어는 굵게 쓴다. 글 끝에 이전 글, 목차, 다음 글로 가는 링크가 있다. (Claude가 정함: 긴 글을 여러 쪽으로 나누면 공책에 정리할 때 앞뒤를 오가기 불편하다.)
- **분위기**: 종이 바탕, 세리프 글씨 등 기존 사전과 같다. 긴 글이 읽기 편한 줄 길이와 줄 간격을 쓴다.
- **휴대폰**: 같은 종이 느낌을 유지하고 글이 화면 폭에 맞게 흐른다.

## 9. 매주 채우는 방식

- 정해진 일정(scheduled task)이 일주일에 한 번 돈다. 정확한 요일과 시간은 만드는 사람에게 맡긴다. 다만 기존 월간 재검토(매달 1일 10:00)와 겹치지 않게 한다.
- 한 번 돌 때 하는 일: 7번 순서에서 다음 주제를 고른다 → 출처를 찾아 글을 쓴다 → 다른 검토자가 대조한다 → 검사와 테스트가 통과하면 올린다 → 한국어로 짧게 보고한다.
- 검토를 통과하지 못하면 그 주는 올리지 않고, 이유를 보고한다.
- 첫 글은 일정을 만들 때 바로 하나 써서 올린다. (Claude가 정함: 사용자가 바로 공부를 시작할 수 있게)

## 10. 관리 시스템과의 관계

- 노션 작업 "향 노트 기초"의 작은 목표는 지금 "좋아하는 향수 하나를 탑·미들·베이스 노트로 나눠 설명해 보기"다. 향을 맡을 수 없으니 "향 공부 입문 글을 읽고 공책에 정리하기"처럼 바꾸고, 향 공부 권 링크를 단다.
- 노션 홈의 사전 링크는 그대로 둔다. 표지에서 향 공부로 들어갈 수 있다.

## 11. 검토 뒤에 정한 것 (Claude가 정함)

- **출처 범위**: 무료로 열어 볼 수 있고 나중에 다시 확인할 수 있는 온라인 자료만 쓴다. 영어 자료도 쓰되 글은 한국어로 풀어 쓴다. 책과 유료 자료는 직접 확인할 수 없어서 쓰지 않는다. 자료가 부족한 뒤쪽 단계 주제는 합치거나 미룬다. 지어내서 채우지 않는다.
- **실제 향수 이름**: 계열의 유래나 역사, 구조를 설명할 때만 실제 향수 이름을 쓴다. 추천, 평가, 구매 안내는 하지 않는다.
- **사전에 없는 재료**: 글에 나와도 링크 없이 둔다. 사전 항목은 매주 일정에서 늘리지 않고, 사용자가 따로 요청할 때 늘린다.

## 12. 만드는 사람에게 맡기는 것

- 글 데이터의 형식과 저장 방법 (정적 파일이어야 한다)
- 주소 구조, 목차와 글 지면의 세부 배치
- 매주 일정의 요일과 시간
- 7번 순서의 세부 조정 (단계의 차례는 지킨다)
- 검사기(validate)가 글에서 확인할 항목
