설계 문서 — 꽃·향 사전 "음악 공부" 권 (2026-10-25)

이 문서는 꽃·향 사전 사이트(https://dldbsgh-design.github.io/flora-dictionary/)에 음악 공부를 더하는 설계다. 바로 앞의 "향 공부" 설계(`docs/superpowers/specs/2026-10-23-scent-study-design.md`)와 그 구현을 그대로 이어받는다. 이 문서에 따로 적지 않은 규칙은 향 공부 설계를 따른다.

## 1. 왜 만드는가

연습 세계(버튜버 위도)의 다음 단계는 "대표 BGM"이다. 사용자가 원하는 대표 BGM은 두 가지로 이루어진다.

- **물건 음악**: 사이트나 게임에서 소지품을 집거나 누르면, 그 물건의 분위기에 맞는 장르의 짧은 음악이 나온다. 가사는 없다. 사용자가 든 예는 만년필에서 재즈, 비녀에서 국악이나 밴드 음악이다.
- **엔딩 노래**: 모든 것을 둘러본 마지막에, 게임으로 치면 엔딩 뒤에 나오는 가사 있는 노래 한 곡이다. 물건 음악과 멜로디로 이어지지 않는 완전히 새로운 곡이고, 위도라는 인물 전체를 아우른다. 사용자가 직접 가사를 쓰고 직접 부른다.

사용자는 작곡, 작사, 보컬에 대한 지식이 전혀 없다. 음악 앱도 써 본 적이 없다. 사용자는 "작업을 위해서는 공부가 필수"라고 했다. 공부 방식은 향 공부와 같다. 글을 읽으며 실물 공책에 자기 방식으로 정리한다.

## 2. 목표, 하지 않을 것, 실패로 보는 것

**목표**
- 사전에 "음악 공부" 권을 더한다. 과목은 **작곡**, **작사**, **보컬** 세 가지다.
- 과목마다 일주일에 한 편씩 글이 늘어난다. 향 공부까지 합치면 일주일에 네 편이다.
- 사용자가 "○○ 다음 글 써 줘"라고 하면 일정과 상관없이 그 과목의 다음 글을 쓴다.
- 보컬은 세 가지를 모두 다룬다.
  - 원리를 배우는 글
  - 매일 따라 하는 **연습 순서** 한 장
  - 스스로 연구하는 방법: 녹음해 듣고 비교하기
- 연습 순서는 보컬 글이 늘어날 때마다 새로 배운 연습이 더해진다.
- 작곡 과목은 물건 음악에 필요한 장르 이해와, 실제로 곡을 만드는 앱 사용법까지 다룬다. 장르에는 재즈, 국악, 밴드 음악, 팝, 성가 계열이 포함된다. 인물 이해의 "팝 or 재즈 or 밴드 / CCM 같은 성스러운 느낌"도 이 범위에 든다.
- 글은 향 공부처럼 길고 자세하다. 듣지 않아도 이해되게 쓰되, 들어 볼 수 있는 예시가 있으면 링크를 단다.

**하지 않을 것**
- 사용자 대신 곡을 만들거나, 가사를 쓰거나, AI로 음악을 만드는 것. 사용자는 손으로 직접 만들고 싶어 한다.
- 대표 BGM의 실제 제작. 그것은 사용자가 공부하며 하는 작업이고, 노션에서 관리한다.
- 퀴즈, 점수, 진도 체크 기능
- 유료 앱이나 장비 구매 안내
- 음원을 사이트에 올리는 것

**실패로 보는 것**
- 향 공부와 같다: 거짓 내용, 관련 없는 내용, 저작권 있는 글의 복사
- 보컬 연습이 목을 다치게 할 수 있는 방식으로 안내되는 것
- 불법 공유된 음원으로 가는 링크
- 순서가 뒤죽박죽이라 앞 글을 몰라서 뒤 글을 이해할 수 없는 것
- 기존 "향 공부" 권의 주소나 글이 깨지는 것

## 3. 사용자와 조건

- 무료로만 만든다. 사이트는 GitHub Pages의 정적 사이트 그대로다.
- 사용자는 학교에 다니지 않아서 공부할 시간이 있다. 공부를 작업의 필수 조건으로 여긴다.
- **기기 (사용자가 확인함)**: 사용자는 Windows 컴퓨터, 아이패드, 아이폰을 쓴다. 음악 앱과 마이크는 써 본 적이 없다.

## 4. 사용자가 정한 것

- 대표 BGM의 구조: 물건 음악(가사 없음, 물건마다 장르)과 엔딩 노래 한 곡(가사 있음, 완전히 새 곡, 인물 전체를 담음, 직접 작사하고 노래함)
- 공부 과목: 작곡, 작사, 보컬
- 보컬은 연습 순서를 따라 하기, 원리 배우기, 스스로 연구하기를 모두 한다.
- 속도: 과목마다 일주일에 한 편이다. 더 원하면 그때그때 요청한다.
- 공부 방식: 향 공부와 같다. 사이트에 쌓고, 읽으며 공책에 정리한다. 과제는 없고 설명은 길게 쓴다.
- 거짓 내용과 관련 없는 내용은 절대 넣지 않는다.
- 핵심 내용이 출처 한 곳에서만 확인되면 "○○에 따르면"처럼 출처를 밝혀 쓸 수 있다. 향 공부에서 정한 규칙과 같다.

## 5. 정확도와 출처 규칙

향 공부 설계 §6의 규칙을 모두 따른다. 출처, 두 사이트 확인, 출처를 밝혀 쓰기, 비유 규칙이 그것이다. 비유 규칙에서 "냄새"는 "소리"로 바꿔 읽는다. 아래 규칙을 더한다.

- **보컬 안전** (Claude가 정함)
  - 보컬 글과 연습 순서에는 목을 보호하는 주의점을 넣는다. 아프거나 목이 쉬면 멈추기, 무리하게 높거나 크게 내지 않기 같은 것이다. 주의점에도 출처가 있어야 한다.
  - 연습 순서의 각 연습은 출처가 있는 글에서만 가져온다.
  - 출처끼리 방법이 다르면 다르다고 밝힌다.
  - 의학적 진단은 하지 않는다. 증상이 오래가면 전문가를 찾으라는 안내만 출처와 함께 적는다.
- **들어 볼 예시 링크** (Claude가 정함)
  - 합법적으로 공개된 곳으로만 링크한다: 저작권이 끝난 녹음, 자유 라이선스 음원(위키미디어 공용 등), 공식 채널이나 공식 사이트.
  - 링크는 예시일 뿐이다. 그 링크 하나로 사실을 뒷받침하지 않는다.
- **앱 사용법** (Claude가 정함): 앱의 기능과 사용법은 앱을 만든 회사의 공식 도움말을 우선 출처로 쓴다. GarageBand라면 Apple 지원 문서다.
- **작사**: 가사의 구조와 기법을 가르친다. 실제 노래의 가사는 저작권 때문에 길게 인용하지 않는다. 짧은 인용도 꼭 필요할 때만, 출처를 밝혀서 쓴다.

## 6. 순서 (초안, Claude가 정함. 사용자가 바꿀 수 있다)

단계는 향 공부와 같이 입문 → 기초 → 중급 → 심화 → 전문이다. 과목마다 따로 이 단계를 밟는다.

- **작곡**
  - 입문: 소리와 음악의 기본(음높이, 박자, 리듬) / 음계와 조 / 멜로디란 / 화음과 코드의 기초 / GarageBand 처음 써 보기 / BandLab 처음 써 보기
  - 기초: 곡의 구조(도입, 반복, 마무리) / 짧은 반복 음악(루프) 만들기 / 악기와 음색 / 장르의 특징: 재즈, 국악, 밴드 음악, 팝, 성가 계열
  - 중급: 코드 진행 / 편곡의 기초 / 분위기를 소리로 옮기는 법 / 물건 음악처럼 짧은 곡을 설계하기
  - 심화와 전문: 화성의 심화 / 장르별 깊이 / 믹싱의 기초 / 작곡가의 작업 과정
- **작사**
  - 입문: 가사란 무엇인가 / 노래의 구조(절, 후렴 등) / 운율과 말의 리듬
  - 기초: 멜로디에 말을 붙이는 법 / 이야기와 인물을 가사로 / 비유와 이미지
  - 중급 이후: 한국어 가사의 특징 / 고쳐 쓰기 / 작사가의 작업 과정
- **보컬**
  - 입문: 목소리가 나는 원리 / 호흡 / 바른 자세 / 목을 보호하는 법
  - 기초: 발성 / 음정 맞추기 / 소리의 울림 / 녹음해서 내 목소리 듣기
  - 중급 이후: 음역과 성구 / 표현과 감정 / 노래 한 곡을 연습하는 순서 / 보컬 트레이너가 가르치는 방식

## 7. 화면

- **표지**: "음악 공부" 권을 더한다. 기존 권의 형식을 따른다.
- **음악 공부 목차**: 과목별(작곡, 작사, 보컬)로, 그 안에서는 단계별로 지금까지 나온 글을 보여 준다.
- **글 지면**: 향 공부와 같다. 한 지면에서 쭉 내려 읽고, 소제목에 번호를 붙이고, 비유 앞에 "비유하자면"을 붙이고, 출처 번호와 출처 목록을 단다. 들어 볼 예시 링크는 출처 목록과 구분되게 둔다.
- **보컬 연습 순서**: 한 지면에 오늘 따라 할 연습을 차례로 적는다.
  - 연습마다 하는 방법, 시간이나 횟수, 주의점, 출처를 적는다.
  - 맨 위에 목 보호 주의점을 둔다.
  - 보컬 목차에서 바로 갈 수 있다.
- **기존 향 공부**: 주소(`#/study`, `#/study/<id>`)와 글이 그대로 열려야 한다.

## 8. 매주 채우는 방식

- 과목마다 매주 일정을 하나씩 둔다. 기존 향 공부 일정(월요일 14:00)과 월간 재검토(매달 1일 10:00)와 겹치지 않게 다른 요일에 둔다.
- 한 번 돌 때 하는 일은 향 공부 일정과 같다. 다음 주제 고르기, 출처 찾아 쓰기, 다른 검토자 대조, 검사 통과 뒤 올리기, 한국어 보고 순서다.
- 보컬 일정은 글을 쓴 뒤 연습 순서도 고친다. 고친 연습 순서도 검토자가 확인한다.
- 각 과목의 첫 글은 일정을 만들 때 바로 하나씩 써서 올린다.
- 월간 재검토에 음악 공부 글과 연습 순서도 넣는다.
- 사용자가 따로 요청하면 그 과목의 다음 글을 바로 쓴다. 과정은 일정과 같다.

## 9. 관리 시스템과의 관계

- 노션 "대표 BGM" 페이지에 구조를 적는다. 물건 음악(물건마다 장르)과 엔딩 노래(새 곡, 직접 작사하고 노래함)를 적고, 음악 공부 링크를 단다.
- 노션 "무료 음악 앱 사용법"의 작은 목표는 지금 "30초짜리 반복되는 분위기 곡 하나를 만들어 MP3로 내보내기"다. 그대로 두고, 음악 공부 링크만 단다.
- 작사와 보컬은 노션에 배우기 작업이 없다. "작사 기초"와 "보컬 기초" 배우기 작업을 더하고, 대표 BGM의 앞 작업으로 잇는다.

## 10. 검토 뒤에 정한 것

- **작곡 도구 (사용자가 정함)**: 패드에서는 GarageBand, 컴퓨터에서는 BandLab을 쓴다.
  - 앱 사용법 글은 두 앱을 모두 다룬다. GarageBand는 아이패드 기준이고, 아이폰에서 다른 점이 있으면 함께 적는다. BandLab은 Windows 컴퓨터의 브라우저 기준이다.
  - 기능과 사용법은 각 회사의 공식 도움말로 확인한다. GarageBand는 Apple 지원 문서, BandLab은 BandLab 공식 도움말이다.
  - GarageBand 곡 파일은 Windows에서 열 수 없다. 그래서 두 앱 사이에 작업을 옮기는 방법을 공식 도움말로 확인해 가르친다. 소리 파일로 내보내서 가져오는 방법 같은 것이다. (Claude가 정함)
  - BandLab의 AI 작곡 기능은 가르치지 않는다. 사용자가 직접 만들고 싶어 하기 때문이다. (Claude가 정함)
  - 녹음은 기기에 달린 마이크로 시작한다.
  - 노션 "무료 음악 앱 사용법"의 목표(MP3로 내보내기)가 두 앱 중 하나에서 안 되면, 되는 앱과 형식으로 바꾸고 사용자에게 알린다.
- **연습 순서의 길이 (Claude가 정함)**
  - 연습 순서는 칸이 정해진 하루 연습이다. 칸은 준비 운동, 호흡, 발성, 음정, 마무리처럼 둔다.
  - 새 보컬 글에서 더 나은 연습을 배우면, 덧붙이지 않고 그 칸의 연습을 바꾼다.
  - 전체 연습 시간은 출처에서 권하는 범위 안으로 정하고 지면에 적는다. 출처마다 다르면 다르다고 밝힌다.
  - 지면은 지금의 연습 순서만 보여 준다. 예전 연습 순서는 저장소 기록에 남는다.
- **월간 재검토 범위 (Claude가 정함)**: 사전 항목 10개와 공부 글 10편(향과 음악을 합쳐, 가장 오래 확인하지 않은 것부터)을 따로따로 확인한다. 연습 순서는 매달 확인한다.

- 일정의 요일과 시간
- §6 순서의 세부 조정 (단계의 차례는 지킨다)
