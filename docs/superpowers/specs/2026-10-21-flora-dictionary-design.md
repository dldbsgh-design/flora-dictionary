설계 문서 — 꽃·향 사전 사이트 (2026-10-21)

원본: 노션 "설계 문서 — 꽃·향 사전 사이트" (https://app.notion.com/p/4000a424355c81d9b057c014e8519c72). 이 파일은 저장소 안의 사본이다.

## 1. 왜 만드는가

포트폴리오 "Total Life Design"에서는 인물마다 대표 꽃(꽃말 기반)과 시그니처 향(노트 구성)을 정해야 한다. 그런데 사용자는 꽃과 향의 종류를 많이 알지 못한다. 인터넷에서 찾으면 유명한 꽃만 나오고, 진짜 있는 꽃인지 확인하거나 사진과 느낌을 보는 것도 번거롭다.

노션으로 시험용 꽃 도감을 만들어 봤지만 두 가지 문제가 있었다.
- 관리 시스템 홈과 같은 곳에 있어서 페이지가 너무 길어지고, 원래 정보를 찾아가기 번거로웠다.
- 수백 가지 꽃을 넘기며 고르는 데는 노션이 맞지 않는다.

그래서 **종이 사전 같은 전용 사이트**를 만든다. 사용자는 요즘 느낄 수 없는 이 감각이 좋고, 공부하는 느낌도 든다고 했다.

## 2. 목표, 하지 않을 것, 실패로 보는 것

**목표**
- 수백 가지(나중에는 수천 가지) 꽃과 향 재료를 종이 사전처럼 넘기며 구경하고, 색인으로 원하는 곳을 바로 펼칠 수 있다.
- 인물 이해에서 나온 분위기 단어로 꽃과 향을 함께 찾을 수 있다.
- 꽃을 고르면 관련된 향 재료로 넘어가고, 향 재료에서도 관련 꽃으로 넘어갈 수 있다.
- 내용에 출처가 있어서 진짜인지 확인할 수 있다.
- Claude 없이 휴대폰, 패드, 컴퓨터 브라우저에서 언제든 열린다.

**하지 않을 것**
- 실제 향수 제품 도감 (향 파트는 재료만 다룬다)
- 회원 가입, 댓글, 사용자가 사이트에서 직접 편집하는 기능
- 상업적 사용

**실패로 보는 것**
- 틀린 정보가 사실처럼 적혀 있는 것 (특히 출처 없는 꽃말)
- 사진 라이선스를 지키지 않은 것
- 한 화면에 꽃 하나만 나와서 많이 보는 데 오래 걸리는 것
- 종이 사전이 아니라 평범한 쇼핑몰이나 목록 사이트처럼 보이는 것
- 휴대폰에서 보기 불편한 것

## 3. 사용자와 조건

- 아직 돈이 없는 나이라 무료로만 만든다.
- 노션과 피그마 모두 처음이고, 개발 지식은 없다. 사이트를 만들고 내용을 채우는 일은 Claude가 한다.
- 이 컴퓨터에는 Git과 Node.js가 설치되어 있다. 파이썬과 GitHub CLI(`gh`)는 없다. GitHub 계정은 아직 없어서 사용자가 직접 만들어야 한다(Claude는 계정을 만들 수 없다).
- 사이트는 GitHub Pages로 공개된다. 주소를 아는 사람은 누구나 볼 수 있고, 사용자도 이 점을 알고 골랐다.
- 나중에 입시 포트폴리오 사이트를 만들 때 이 자료를 다시 쓸 수 있으면 좋다.

## 4. 사용자가 정한 것

- **형태**: GitHub Pages에 올리는 무료 정적 사이트, 이름은 "꽃·향 사전"(가칭)
- **두 파트**: 같은 사이트 안에 "꽃"과 "향" 파트를 나눈다.
- **지면**: 종이 사전 느낌. 한 지면에 항목 3개 이상, 사진은 작게. 옆면 색인 탭, 이전·다음 장 넘기기, 쪽 번호. 시안(아래 7번)의 형식이 좋다고 했다.
- **분위기**: 종이 바탕, 세리프 글씨, 옛 식물도감 같은 톤. FigJam 아이디어 보드와 이어지는 느낌.
- **꽃 항목**: 이름, 학명, 다른 이름, 특징, 색, 계절, 꽃말, 어울리는 꽃.
  - 꽃말이 없는 꽃도 넣는다. 꽃말 칸은 비워 둔다. "꽃 자체로 다른 꽃과 어울려 쓸 가능성이 있다."
- **처음 채울 꽃**: 유명한 꽃 위주에, 덜 알려졌지만 알아 두면 좋은 꽃을 섞는다.
- **향 파트**: 실제 향수가 아니라 향의 재료(베르가못, 베티버, 아이리스 등).
- **정확도**: 내용은 계속 다시 검토해서 오류가 없게 한다.
- **사진 출처**: 상업적 사용 계획은 없지만, 출처 표시가 필요하다는 설명을 듣고 받아들였다.

## 5. 항목 내용

### 5.1 꽃
- 이름(한국어), 학명, 다른 이름(한국어 별명, 영어 이름)
- 과(科), 원산지
- 특징: 한두 줄. 모양, 피는 방식, 쓰임 등
- 색: 정해진 목록에서 여러 개
- 계절: 피는 시기 (봄, 여름, 가을, 겨울에서 여러 개)
- 꽃말: 있을 때만. 꽃말마다 어느 나라에서 전해지는지(한국, 일본, 영미권 등)와 출처를 적는다. 확인이 안 되면 "확인 필요"로 표시한다.
- 분위기: 정해진 분위기 단어 목록에서 여러 개. 향 파트와 같은 목록을 쓴다.
- 어울리는 꽃: 색 조화, 같은 계절, 꽃다발에서 함께 쓰이는지를 기준으로 연결한다 (Claude가 정함).
- 관련 향 재료: 향 파트와 연결
- 사진 1장(작게), 사진 출처(찍은 사람, 라이선스, 원본 링크)
- 내용 출처 링크

### 5.2 향 재료
- 이름(한국어, 영어), 원료(식물이나 물질)
- 계열: 시트러스, 플로럴, 그린, 우디, 스파이시, 앰버, 머스크, 아쿠아틱, 구르망 등
- 노트 위치: 탑, 미들, 베이스
- 향 묘사: 조향 자료에서 공통으로 쓰는 표현을 바탕으로 쓰고 출처를 단다.
- 분위기: 꽃과 같은 단어 목록
- 천연 / 합성
- 어울리는 재료
- 관련 꽃: 꽃 파트와 연결
- 사진 1장(작게), 사진 출처, 내용 출처

## 6. 정확도와 출처 규칙

- 학명, 과, 원산지, 피는 시기, 색은 출처가 분명한 자료(위키백과, 위키데이터, 식물 데이터베이스 등)에서 가져오고 출처를 남긴다.
- 꽃말은 사실이 아니라 전해지는 이야기다. 나라와 출처를 함께 적는다.
- 향 묘사는 주관적이라 공통 표현과 출처를 기준으로 한다.
- **채우는 방식**: 꽃은 첫 묶음 60개 정도(유명한 꽃과 덜 알려진 꽃을 대략 2:1), 향 재료는 첫 묶음 40개 정도로 시작한다. 이후 몇십 개씩 늘린다.
- **검토**: 묶음마다 다른 검토자가 내용과 출처를 한 번 더 확인한다.
- **사진**: 위키미디어 공용처럼 자유 라이선스 사진만 쓴다. 사진 아래에 "사진: 찍은 사람 / 라이선스"를 작은 글씨로 단다. CC0나 퍼블릭 도메인도 같은 방식으로 적는다. 사진은 사이트 안에 작은 크기로 저장해서, 외부 사이트가 막혀도 보이게 한다.

## 7. 화면

- **표지**: "꽃"과 "향" 중 하나를 골라 들어간다.
- **지면** (사용자가 좋다고 한 시안): 위에 머리글(파트 이름, 이 지면의 가나다 범위). 항목 3개 이상이 세로로 놓이고, 각 항목은 작은 사진, 이름, 학명·별명, 꽃말과 한 줄 특징, 태그(색, 계절, 분위기)로 되어 있다. 아래에 이전 장, 쪽 번호, 다음 장이 있다.
- **옆면 색인 탭**: 가나다, 색, 계절(꽃) / 가나다, 계열, 노트 위치(향). 탭을 누르면 그 기준으로 묶인 지면으로 펼쳐진다.
- **분위기 단어로 찾기**: 단어를 고르면 맞는 꽃과 향이 함께 나온다.
- **항목 자세히 보기**: 항목을 누르면 출처, 어울리는 것, 관련 항목이 모두 보인다.
- **휴대폰**: 같은 종이 느낌을 유지한다. 색인 탭 위치처럼 화면에 맞춘 배치는 만드는 사람에게 맡긴다.

### 7.5 앞으로 더할 파트 (사용자가 미리 말해 둠)
- 포트폴리오 구성에는 꽃과 향 말고도 액세서리, 공예 등 여러 분야가 있다. 지금은 꽃과 향만 만들고, 나머지는 나중에 따로 이야기한다.
- 사이트는 파트를 나중에 더할 수 있게 만든다. 표지에 새 파트를 추가하고, 같은 지면 형식과 분위기 단어를 돌려 쓸 수 있어야 한다.

## 8. 관리 시스템과의 관계

- 사전은 노션 홈과 따로 있다. 노션 홈의 "모든 페이지"에 사전 링크 하나만 둔다.
- 노션의 "꽃 도감 (시험용)"은 이 사전이 생기면 필요 없어진다. 지울지는 사용자가 정한다.
- 연습 세계의 "대표 꽃", "시그니처 향" 작업에서 사전을 보고 고르면 된다.

## 9. 검토 뒤에 정한 것

- **꽃말 출처 기준 (사용자가 정함)**: 꽃집이나 꽃말 사이트도 출처로 인정한다. 단, 서로 다른 출처 두 곳 이상에서 같은 꽃말이 나올 때만 확인된 꽃말로 적고, 출처 링크를 모두 단다. 한 곳에서만 나오면 "확인 필요"로 둔다.
- **재검토 (사용자가 정함)**: 항목마다 "마지막 확인 날짜"를 둔다. 한 달에 한 번 정해진 일정으로 가장 오래 확인하지 않은 항목부터 다시 확인한다.
- **항목 단위 (Claude가 정함)**: 사람들이 부르는 꽃 이름 하나가 항목 하나다(예: "장미"). 대표 종이나 품종은 그 항목의 특징에 적고 따로 만들지 않는다. 학명은 그 이름이 가리키는 종 또는 속을 적는다.
- **올리는 방법 (Claude가 정함)**: 사용자가 GitHub 계정과 빈 저장소를 만들고, 첫 업로드 때 열리는 브라우저 창에서 한 번 로그인한다(Git에 들어 있는 Git Credential Manager가 처리한다). 그 뒤로는 Claude가 내용을 채우고 저장소에 올린다.
- **시험용 도감 (Claude가 정함)**: 노션 "꽃 도감 (시험용)"의 꽃 5개(헬레보루스 니게르, 니겔라 다마스케나, 스카비오사, 블루스타, 빌리버튼)를 첫 묶음에 넣고, 새 기준으로 다시 확인한다.
- **시안과 보드**: 무드 참고는 FigJam 아이디어 보드 https://www.figma.com/board/rW3vr5nPJRCUWRJELLV7Cf 이다. 종이 바탕은 따뜻한 회색(#EFEBE2 근처), 글씨는 진한 먹색, 학명은 이탤릭, 태그는 얇은 테두리 상자, 색인 탭은 오른쪽 옆면의 세로 탭이다.

## 10. 만드는 사람에게 맡기는 것

- 기술 구성: 정적 사이트, 데이터 파일 형식, 사진 처리 방법. 단 무료이고 GitHub Pages에서 돌아가야 한다.
- 색, 분위기, 계열 목록의 정확한 단어
- 지면당 항목 수(3개 이상), 휴대폰 배치, 넘기는 효과
- 첫 묶음에 어떤 꽃과 재료를 넣을지 (4번과 6번 기준을 따른다)
- 사이트 주소 이름
