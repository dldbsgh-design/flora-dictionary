# 꽃·향 사전

꽃과 향 재료를 종이 사전처럼 찾아볼 수 있는 웹사이트입니다. Total Life Design 포트폴리오를 위해 만들었습니다.

지금은 네 부분이 있습니다.

- **꽃**: 60개
- **향**: 향 재료 40개
- **향 공부**: 향과 조향을 처음부터 배우는 긴 글. 일주일에 한 편씩 늘어납니다 (`data/lessons.json`).
- **음악 공부**: 작곡, 작사, 보컬을 처음부터 배우는 긴 글. 과목마다 일주일에 한 편씩 늘어납니다. 보컬은 매일 따라 하는 "오늘의 연습 순서"도 있습니다 (`data/routine.json`). 새 글은 매주 화요일(작곡), 수요일(작사), 목요일(보컬) 오후에 올라옵니다.

나중에 새 부분(예: 나무, 허브)을 더 붙일 수 있게 만들어 두었습니다.

---

## 내용을 믿을 수 있게 하는 방법

이 사전은 "그럴듯한 말"이 아니라 "확인한 내용"만 싣는 것을 목표로 합니다.

- **출처와 마지막 확인 날짜**: 모든 항목에는 출처가 붙어 있고, "마지막 확인" 날짜가 적혀 있습니다.
- **꽃말**: 서로 다른 사이트 2곳 이상에서 확인되어야 "확인함"으로 표시합니다. 그렇지 않으면 "확인 필요"로 보여 줍니다.
- **꽃말이 알려지지 않은 꽃**은 꽃말을 아예 보여 주지 않습니다. 없는 말을 지어내지 않습니다.
- **사진**: Wikimedia Commons에 있는, 자유롭게 쓸 수 있는 라이선스의 사진만 씁니다. 사진마다 "사진: 찍은 사람 / 라이선스" 형태로 출처를 적습니다.
- **한 달에 한 번 다시 확인**: 마지막 확인 날짜가 가장 오래된 항목부터 다시 확인합니다. 향 공부·음악 공부 글과 연습 순서도 함께 다시 확인합니다.
- **향 공부 글**: 모든 문단에 출처 번호가 붙습니다. 핵심 정의와 숫자는 서로 다른 사이트 2곳 이상에서 확인합니다. "비유하자면"으로 시작하는 문단은 이해를 돕기 위한 비유이고, 새로운 사실을 더하지 않습니다. 글마다 다른 검토자가 출처를 다시 열어 확인한 뒤에 올립니다.
- **보컬 연습**: 연습 순서의 모든 연습과 주의점에도 출처가 있습니다. 목이 아프거나 쉬면 멈추세요.

## 내 컴퓨터에서 미리 보기

미리 보기를 하려면 **Node.js**가 필요해요. https://nodejs.org 에서 LTS 버전을 설치하세요. 이것은 내 컴퓨터에서 미리 볼 때만 필요하고, 인터넷에 공개된 사이트를 보는 데는 아무것도 설치하지 않아도 됩니다.

1. 터미널(명령을 글자로 입력하는 창)을 엽니다. Windows에서는 시작 메뉴에서 'PowerShell'을 검색해 열고, `cd` 명령으로 이 폴더로 이동합니다. (예: `cd C:\Users\내이름\Documents\flora-dictionary`)
2. 아래 명령을 입력합니다.

   ```
   node scripts/serve.mjs
   ```

3. 인터넷 브라우저에서 http://localhost:8080 을 엽니다.
4. 끝내려면 터미널에서 `Ctrl + C`를 누릅니다.

## 인터넷에 공개하기 (처음 한 번만)

GitHub Pages라는 무료 서비스를 사용합니다. 아래 순서대로 하시면 됩니다.

1. **GitHub 계정을 만듭니다.** https://github.com 에서 가입하세요.
2. **빈 저장소(프로젝트 보관함)를 만듭니다.** 이름은 `flora-dictionary`로 하고, 공개(Public)로 설정합니다. "Add a README file"은 **체크하지 마세요.** (이미 README가 있기 때문입니다.)
3. **저장소 주소를 Claude에게 알려 주세요.** 그러면 Claude가 작업 내용을 먼저 main 브랜치에 합친 뒤 `git remote add origin …`과 `git push -u origin main`을 실행해 파일을 올려 줍니다. 이때 브라우저에 GitHub 로그인 창이 한 번 나타납니다. 로그인해 주세요.
4. GitHub의 저장소 화면에서 **Settings → Pages**로 갑니다. **Branch**는 `main`, 폴더는 `/ (root)`로 고르고 **Save**를 누릅니다.
5. 몇 분 뒤 같은 화면에 사이트 주소가 나타납니다. 주소는 `https://<내 GitHub 이름>.github.io/flora-dictionary/` 모양입니다. 이 주소를 저장해 두세요.

## 내용 더 추가하거나 고치기

직접 파일을 고칠 필요 없이, Claude에게 말로 부탁하면 됩니다.

- "꽃 30개 더 추가해 줘"
- "이 꽃 정보 다시 확인해 줘"

추가하거나 고친 뒤에는 Claude가 검사를 돌려 출처, 날짜, 사진 크레딧이 빠지지 않았는지 확인합니다.

## 폴더 안내

| 이름 | 하는 일 |
| --- | --- |
| `index.html` | 사이트의 첫 화면 |
| `css/` | 모양(디자인) |
| `js/` | 화면이 움직이는 방식 |
| `data/` | 꽃(`flowers.json`), 향(`scents.json`), 공부 글(`lessons.json`), 보컬 연습 순서(`routine.json`) 등 사전 내용 |
| `images/` | 사진 |
| `scripts/` | 도우미 프로그램 (미리 보기, 내용 검사, 사진 가져오기) |
| `tests/` | 자동 검사 |
| `docs/` | 설계 문서 |
